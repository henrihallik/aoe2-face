# Required In-Game Screenshots

The competition asks for a few screenshots. The layout reference is not a substitute for these.

1. `01-captureage-overview.png`: complete map stitched from UI-free AoE2 DE views, with the smiling face immediately readable.
2. `02-smile-and-nose.png`: closer view showing raised cheeks, nose ridge, moustache, white teeth, and the upturned lower mouth.
3. `03-ear-start.png`: one player start showing the Town Center, 9 villagers, nearby food, hair woodline, beard woodline, and dockable coast.
4. `04-hybrid-routes.png`: gameplay view showing the open central land route and ships using the surrounding water ring.

Use 1920 x 1080 or smaller PNG files. Hide unrelated desktop UI, keep the minimap visible in at least one image, and do not use the SVG/PNG design diagram as an in-game screenshot.
